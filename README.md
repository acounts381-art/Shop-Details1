# Shop Details App (APK)

1. Is poore folder ki saari files GitHub repository me upload karein (`.github` folder samet).
2. GitHub me **Actions** tab kholen, **Build APK** chalne dein (ya "Run workflow" dabayen).
3. Build mukammal hone par us run me neeche **Artifacts** se `shop-details-apk` download karein.
4. Zip khol kar `app-debug.apk` phone me install karein.
